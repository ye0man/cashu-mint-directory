# Cashu Mint Directory

An interactive directory of Cashu mints.

**[Open the interactive table](https://ye0man.github.io/mint-directory/)**

It is built with [Tabulator](https://tabulator.info/), is fed by [`docs/mints.json`](./docs/mints.json), and supports sorting, filtering, column resizing/reordering, and CSV/JSON export.

The data was compiled from the [Awesome Cashu](https://github.com/cashubtc/awesome-cashu) repo, [MintRadar](https://mintradar.pedani.eu), and direct queries to each mint’s `/v1/info` endpoint.

To update the data manually, regenerate `docs/mints.json` and commit it to this repo.
